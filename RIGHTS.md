# Asset rights

The licence question is answered, and the answer is now permissive: **Slimer's
art is entirely original and the game can be sold.**

## What changed

Slimer previously used thirteen sprites from GDQuest's *Your First 2D Game With
Godot 4* pack. The pack splits its licensing:

- **Code — MIT.** Permissive, commercially fine, and still in use: two effect
  scripts keep the pack's tween choreography. This was never the constraint.
- **Game assets — CC BY-NC-SA 4.0.** This was the constraint. The **NC** clause
  forbids commercial use of the assets in their original *or modified* form, so
  the recoloured enemies — hue rotations of GDQuest's slime — were as
  restricted as the originals. Selling the game was not permitted at any price.

All thirteen have been replaced with original art authored in
`game/tools/gen_art.py`, and the pack files have been deleted from the project.
`tools/copy_assets.py` no longer reads the pack at all.

| Replaced | Now |
| --- | --- |
| `slime_body.png` — source of all six enemy colours | `gen/slime_body.png`, drawn with enough value contrast between its four tones to survive hue rotation |
| `slime_face.png` | `gen/slime_face.png` |
| `boo_body.png`, `boo_face.png` | `gen/boo_body.png`, `gen/boo_face.png` — a pale spirit, deliberately cool against a warm forest so the player never loses themselves in a crowd |
| `pistol.png` | `gen/pistol.png` |
| `projectile.png` | `gen/projectile.png` |
| `muzzle_flash.png` | `gen/muzzle_flash.png` |
| `impact_circle.png` | `gen/impact_circle.png` |
| `pine_tree.png` | `gen/pine_tree.png` |
| `ground_shadow.png` | `gen/ground_shadow.png` |
| 3 potion bottles sliced from 3×3 sheets | `gen/potion_{red,blue,purple}.png`, drawn directly |

Each replacement matches the pixel dimensions and the canvas framing of the
file it replaced. That mattered more than it sounds: the elite crown offset,
the face offsets and the enemy hit radii are all expressed relative to those
frames, so a silhouette sitting differently inside the same canvas would have
left crowns floating above the slimes' heads.

## What the project now contains

**Original and unrestricted:** every sprite in `game/assets/sprites/gen/`,
generated by `tools/gen_art.py`; all 46 sound effects, generated by
`tools/gen_sfx.py`; the four music tracks. Both generators are deterministic,
so the shipped art is reproducible from source.

**MIT, third-party:** the Godot engine, and the tween choreography in
`fx/impact.gd` and `fx/muzzle_flash.gd`. Both require only that the notice in
`game/LICENSE-ASSETS.md` is kept.

Nothing in the build is CC BY-NC-SA any more.

## Still worth checking before a paid release

- **The name "Slimer"** is a Ghostbusters character. That was tolerable for a
  free hobby project and is a different proposition on a store page — worth a
  trademark search and a look at the Steam catalogue.
- **Your music** — if any of it used sample packs or AI tools, check those
  terms. Sample libraries commonly restrict redistributing unaltered loops.
- **The in-game credits screen** still carries the old GDQuest attribution.
  It is no longer required and should be updated to match this file.

I am not a lawyer. The licensing position above is straightforward now that no
CC BY-NC-SA material remains, but if real money depends on it, have someone
qualified confirm.
