# Third-party asset licences

**Slimer's art, sound and music are entirely original work.** No third-party
assets remain in the game.

This file used to document thirteen sprites taken from GDQuest's *Your First 2D
Game With Godot 4* starter pack, which are licensed CC BY-NC-SA 4.0. Those
sprites have been replaced with original art and removed from the project.

---

## Art — original

Every sprite in `assets/sprites/gen/` is generated by `tools/gen_art.py`, and
every sound in `assets/sfx/` by `tools/gen_sfx.py`. Both are deterministic:
re-running them reproduces the exact art the game ships with.

That includes the thirteen replacements authored to retire the pack: the base
slime that all six enemy colours are hue-rotated from, the slime eyes, the
player body and face, the pistol, the bullet, the muzzle flash, the impact
puff, the pine tree, the actor shadow, and the three potion bottles. They are
drawn to the same pixel dimensions as the files they replaced, so nothing
downstream had to be re-tuned.

Copyright Tanav Yedlapalli. See `../LICENSE` for the terms the project ships
under.
