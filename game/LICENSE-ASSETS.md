### Files used, and the changes made to them

| File | Used as | Modified? |
| --- | --- | --- |
| `slime_body.png` | Source for all six enemy colours | **Yes** — hue-rotated to red, blue, yellow, purple and orange in `tools/gen_art.py`, preserving the original shading |
| `slime_face.png` | Enemy eyes | No |
| `boo_body.png`, `boo_face.png` | The player character | **Yes** — recoloured, given a dark outline copy behind it, and scaled |
| `pistol.png` | The player's gun | No |
| `projectile.png` | Bullets | **Yes** — tinted per shot; brighter and larger on critical hits |
| `muzzle_flash.png` | Muzzle flash | No |
| `impact_circle.png` | Bullet impact puff | **Yes** — tinted per impact type |
| `pine_tree.png` | One of four tree types in the forest | No |
| `ground_shadow.png` | Shadow under every actor | No |
| `poção vermelha.png`, `poção azul.png`, `poção roxa.png` | Health, speed and ability potions | **Yes** — the originals are 3×3 sprite sheets; a single 16×16 bottle is sliced out and scaled 2× in `tools/gen_art.py` |

Everything else in `assets/sprites/gen/` — all five boss sprites, every
environment prop, the ground tiles, all UI icons, coins, particles, the app
icon — and all 46 files in `assets/sfx/` are original work generated by
`tools/gen_art.py` and `tools/gen_sfx.py`, and are not covered by this licence.
